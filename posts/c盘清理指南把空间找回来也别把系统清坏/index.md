# C盘清理指南：把空间找回来，也别把系统清坏


C 盘快满的时候，人很容易进入一种焦虑状态：哪里都想删，哪个文件夹都像坏人。

但 Windows 的系统盘有点特殊，很多目录看起来很占空间，却不能直接手动删除。比较稳妥的思路是：先用系统自带工具清理，再处理自己能确认来源的文件，最后才考虑命令行和高级操作。

<!--more-->

## 先看空间到底花在哪

不要凭感觉删文件，先看结构。

打开：

```text
设置 -> 系统 -> 存储
```

这里可以看到应用、临时文件、文档、图片、桌面、下载等分类各占多少空间。这个页面的好处是相对安全，它不会鼓励你去删系统核心目录。

如果想看得更细，可以用第三方磁盘分析工具，比如 WizTree 或 TreeSize Free。它们适合定位大文件，但删除前还是要先判断来源：自己下载的安装包、视频、压缩包可以处理；系统目录里的东西不要直接动。

## 第一轮：用 Windows 自带清理

最推荐从这里开始。

### 清理临时文件

路径：

```text
设置 -> 系统 -> 存储 -> 临时文件
```

常见可以勾选的项目：

- Windows 更新清理
- 临时文件
- 回收站
- 缩略图
- 传递优化文件
- DirectX 着色器缓存

这里有一个地方要小心：**下载**。如果你的下载目录里还有需要保留的文件，不要随手勾选。

### 开启存储感知

路径：

```text
设置 -> 系统 -> 存储 -> 存储感知
```

它可以自动清理临时文件、回收站和一段时间没用的下载内容。我的建议是保守一点：

- 回收站：30 天后删除
- 下载文件夹：先不要自动清，除非你已经有整理习惯
- 临时文件：可以开启自动清理

## 第二轮：清理你真正认识的东西

系统工具跑完以后，通常还能从日常使用痕迹里找回不少空间。

### 下载目录

`Downloads` 往往是 C 盘空间黑洞。重点看这几类：

- 软件安装包
- 压缩包
- 录屏和视频
- 重复下载的文档
- 大模型、游戏、开发工具的安装文件

清理原则很简单：已经安装过的软件安装包，多数可以删；不确定的文件先移到其他盘，不要立刻永久删除。

### 桌面和文档

很多人习惯把文件直接放桌面，而桌面默认也在 C 盘用户目录下。可以把大文件迁到 D 盘，然后桌面只留快捷方式。

常见位置：

```text
C:\Users\你的用户名\Desktop
C:\Users\你的用户名\Documents
C:\Users\你的用户名\Pictures
C:\Users\你的用户名\Videos
```

如果照片、视频、项目文件很多，建议在 D 盘建一个固定目录，比如：

```text
D:\Files
D:\Projects
D:\Media
```

让 C 盘负责系统和常用软件，别让它承担所有生活压力。

### 应用缓存

浏览器、微信、QQ、钉钉、飞书、剪辑软件、游戏平台都可能吃掉大量缓存。

比较稳的做法是进软件自己的设置里清理缓存，而不是手动到处删目录。尤其是聊天软件，如果你直接删文件夹，可能会把聊天记录、图片或索引弄乱。

可以重点检查：

- 浏览器下载和缓存
- 微信/QQ 文件管理
- Steam、Epic、Battle.net 的游戏库位置
- 剪辑软件的缓存目录
- IDE 和包管理器缓存

## 第三轮：卸载不用的软件

路径：

```text
设置 -> 应用 -> 已安装的应用
```

按大小排序，通常能看到一些很久没打开的软件。卸载比手动删除安装目录更安全，因为卸载程序会顺便清理注册表、服务和快捷方式。

如果一个软件支持更改安装位置，下次安装时尽量放到 D 盘。尤其是游戏、设计软件、视频工具、开发 SDK，这些动辄几十 GB。

## 第四轮：谨慎使用命令行

下面这些适合知道自己在做什么时使用。操作前建议先保存工作，最好也确认电脑没有正在更新系统。

### 关闭休眠文件

如果你不用休眠功能，可以关闭它。管理员 PowerShell 运行：

```powershell
powercfg -h off
```

它会删除 `hiberfil.sys`，通常能释放几个 GB 到十几个 GB。代价是不能再使用休眠功能，部分电脑的快速启动也会受影响。

想恢复可以运行：

```powershell
powercfg -h on
```

### 清理组件存储

管理员 PowerShell 运行：

```powershell
Dism.exe /Online /Cleanup-Image /StartComponentCleanup
```

这个命令会清理一些 Windows 组件存储里的旧版本文件。它比手动删除 `WinSxS` 安全得多，但也不要频繁折腾，偶尔清一次就够。

## 这些地方不要手动乱删

看到它们很大也先忍住：

- `C:\Windows`
- `C:\Windows\System32`
- `C:\Windows\WinSxS`
- `C:\Program Files`
- `C:\Program Files (x86)`
- `C:\ProgramData`
- `C:\Users\你的用户名\AppData`
- `C:\Windows\Installer`

不是说这些目录永远不能清，而是不要用“看哪个大删哪个”的方式清。要么走系统设置，要么走软件自带清理，要么用明确知道作用的命令。

## 一个比较稳的清理顺序

我会按这个顺序来：

1. 打开存储页面，看空间分类。
2. 清理临时文件，谨慎勾选下载目录。
3. 清空回收站。
4. 整理下载、桌面、文档、图片、视频。
5. 卸载不用的软件和游戏。
6. 清理聊天软件、浏览器、剪辑软件缓存。
7. 把大型项目、素材、游戏库迁到 D 盘。
8. 确认不用休眠后，再考虑 `powercfg -h off`。
9. 偶尔运行一次 DISM 组件清理。

## 最后留多少空间比较舒服

C 盘不要刚清完就只剩几 GB。Windows 更新、浏览器缓存、开发工具、聊天软件都会继续写入系统盘。

我的经验是：

- 轻度办公：至少留 30 GB
- 日常主力电脑：尽量留 50 GB 以上
- 开发、剪辑、游戏电脑：越多越好，最好别低于总容量的 15% 到 20%

清理 C 盘不是一次性的“大扫除”，更像整理书桌：真正有用的是建立习惯。下载文件定期归档，大软件尽量装到其他盘，缓存交给工具清，系统目录别硬碰。这样 C 盘就不会隔三差五红给你看了。
