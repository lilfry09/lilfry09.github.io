CLIP

CLIP 模型（Contrastive Language–Image Pre-training，对比语言-图像预训练）的基本结构相对简洁且高度模块化。它主要由两个独立的编码器和一个对比学习目标函数构成，这两个编码器将图像和文本映射到同一个联合嵌入空间中。

CLIP 模型的基本结构如下：

1. 图像编码器（Image Encoder）

  • 功能： 接收原始图像作为输入，并将其转换为一个固定长度的图像嵌入向量（Image Embedding）。
  • 常用架构：
    • 最初的 CLIP 论文采用了两种主要的视觉 Transformer 变体：
      • ResNet-50 的改进版本： 结合了 Attention 机制和一些性能改进。
      • Vision Transformer (ViT)： 图像被分割成一系列的 patch，然后输入到标准的 Transformer 编码器中进行处理。
  • 输出： 一个代表图像语义内容的 $N$ 维向量。

2. 文本编码器（Text Encoder）

  • 功能： 接收描述图像的文本（即 Caption 或 Prompt）作为输入，并将其转换为一个固定长度的文本嵌入向量（Text Embedding）。
  • 常用架构：
    • 一个因果自注意力 Transformer 的变体（如 GPT-2 或类似 Transformer 解码器的结构），用于处理文本序列。
  • 输出： 一个与图像嵌入向量维度相同的 $N$ 维向量。

3. 联合嵌入空间（Joint Embedding Space）

  • 这是 CLIP 的核心所在。图像编码器和文本编码器的目标是将各自的输入映射到一个共享的、多模态的向量空间中。
  • 特性： 在这个空间中，相互匹配的图像和文本（即描述同一事物的图文对）它们的嵌入向量会彼此靠近，而不匹配的图文对的嵌入向量则会彼此远离。

拉格朗日插值法简介

已知函数y=f(x)在n+1个不同点(x0,y0),(x1,y1),…,(xn,yn)(x0 != x1 != … != xn),处的函数值y0,y1,…yn,求次数不大于n的多项式P(x)满足P(xi)=yi(i=0,1,…,n).

唯一性

Cramer法则，Vandermonde行列式 D= | 1 | x0 | x0^2 | … | x0^n | | 1 | x1 | x1^2 | … | x1^n | | 1 | x2 | x2^2 | … | x2^n | != 0 | … | … | … | … | … | | 1 | xn | xn^2 | … | xn^n |

P(x)=y0L0(x)+y1L1(x)+…+ynLn(x)

浮点数在计算机里的表示

一、计算机只能存有限的比特

计算机存储一切东西都是有限比特的二进制数。 整数很好表示，比如 13 是 1101₂。 但一旦出现小数，比如 0.1₁₀，问题就来了——它在二进制里是个无限循环小数：

0.1₁₀ = 0.0001100110011001100...₂ （0011循环）

也就是说，用有限的位数装不下，只能截断或四舍五入，于是产生误差。

快速傅里叶变换（FFT）详解

fry published on 2025-10-13 included in 算法 信号处理

1. 什么是傅里叶变换？

傅里叶变换是一种将信号从时域转换到频域的数学工具。它可以将任意周期信号分解为一系列正弦波和余弦波的叠加。

离散傅里叶变换（DFT）

对于长度为 $N$ 的序列 $x[0], x[1], …, x[N-1]$，其 DFT 定义为：

$$X[k] = \sum_{n=0}^{N-1} x[n] \cdot e^{-i \frac{2\pi}{N} kn}, \quad k = 0, 1, …, N-1$$

其中 $i$ 是虚数单位，$e^{-i\theta} = \cos\theta - i\sin\theta$（欧拉公式）。

时间复杂度问题

直接计算 DFT 需要 $O(N^2)$ 的时间复杂度，因为：

  • 需要计算 $N$ 个频率分量 $X[k]$
  • 每个 $X[k]$ 需要对 $N$ 个时域样本求和

当 $N$ 很大时（如音频处理中 $N=4096$），计算量非常大。

2. 快速傅里叶变换（FFT）

FFT 是一种高效计算 DFT 的算法，由 Cooley 和 Tukey 在 1965 年提出。它将复杂度从 $O(N^2)$ 降低到 $O(N\log N)$。

寻找数组最大值和最小值

fry published on 2025-10-13 included in 算法题解

题目描述

伪代码： FindMinMax(A, left, right) if left = right return A[left], A[left] # 只有一个元素，它既是最大值也是最小值

mid = (left + right) / 2
left_min, left_max = FindMinMax(A, left, mid)      # 递归处理左半部分
right_min, right_max = FindMinMax(A, mid + 1, right) # 递归处理右半部分

total_min = min(left_min, right_min)  # 比较左右部分的最小值
total_max = max(left_max, right_max)  # 比较左右部分的最大值

return total_min, total_max
