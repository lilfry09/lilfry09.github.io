读 OLMo 3：真正重要的不是新架构，而是训练信号

fry 发布于 2026-04-06 收录于 AI

最近读 OLMo 3，我最大的感受不是“开源社区又做出了一个更强的模型”，而是它把一件经常被说得很模糊的事情讲清楚了：

一个大模型最终会长成什么样，核心不是由几处架构微调决定，而是由它在每个阶段反复接收到什么训练信号决定。

这句话听起来很朴素，但如果真把它想透，很多关于 LLM 的问题都会变得更清楚。为什么有些模型底座不差，后训练却拉不上去？为什么有些模型上下文窗口变长了，却还是不会真正利用长上下文？为什么有些 RL recipe 看起来很先进，最后却没有明显收益？答案往往不在“结构又改了什么”，而在“梯度到底从哪里来”。

寻找数组最大值和最小值

fry 发布于 2025-10-13 收录于 算法题解

题目描述

伪代码： FindMinMax(A, left, right) if left = right return A[left], A[left] # 只有一个元素，它既是最大值也是最小值

mid = (left + right) / 2
left_min, left_max = FindMinMax(A, left, mid)      # 递归处理左半部分
right_min, right_max = FindMinMax(A, mid + 1, right) # 递归处理右半部分

total_min = min(left_min, right_min)  # 比较左右部分的最小值
total_max = max(left_max, right_max)  # 比较左右部分的最大值

return total_min, total_max
