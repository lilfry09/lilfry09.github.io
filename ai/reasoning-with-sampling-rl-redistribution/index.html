读《Reasoning with Sampling》：RL 没让模型变聪明，它只是在重分配推理能力

从 power distribution、MCMC 到 inference-time scaling，这篇论文在重新解释“推理增强”到底来自哪里

最近看到一篇我很喜欢的论文：Reasoning with Sampling: Your Base Model is Smarter Than You Think。

它吸引我的地方，不是又提出了一个更复杂的推理框架，而是它把一个现在非常主流、但经常被默认接受的叙事正面顶了回去：

RL 真的让大模型学会了“新的推理能力”吗？

这篇论文给出的回答非常不客气，也非常值得认真看一遍：

不一定。很多时候，RL 更像是在把 base model 原本分散在多次尝试里的能力，重新压缩到单次回答里。

这不是一个小修小补的观点，而是在重新定义“推理增强”到底意味着什么。

如果只记一句话

我觉得这篇论文最核心的一句话就是：

RL 可能并没有让模型变得更聪明，而是在牺牲多样性和 multi-shot reasoning 的前提下，把 pass@k 的能力重分配到了 single-shot 表现上。

论文原文甚至直接写到，RL 可能会把 pass@k 的性能“redistribute”到单次回答上，同时损害多次采样时的推理表现和多样性。ar5iv HTML

这句话非常重要，因为它挑战的不是某个小技巧，而是整个“reasoning model 为什么更强”的常见解释。

为什么这几乎是在否定 RL 的“增益论”

过去大家很容易把现象理解成：

  • base model 本来不会推理
  • 经过 RL 之后，模型学会了更深的推理
  • 所以 RL 创造了新的 reasoning capability

而这篇论文说，也许事情根本不是这样。

它提出的更强解释是：

  • base model 其实已经有不少潜在的正确推理路径
  • 只是这些正确路径平时分散在很多不同 sample 里
  • RL 做的事情，更像是把概率质量集中到少数“稳定的正确路径”上
  • 于是 single-shot 变强了，但生成分布也更尖、更窄了

换句话说，论文否定的不是 “RL 有用”，而是“RL 在凭空造出新能力”这套叙事。

它想说的是：RL 的收益，更可能来自分布锐化，而不是能力凭空涌现。

什么叫“重分配推理能力”

这个地方我觉得可以用一个很直观的类比来理解。

把 base model 想成一个会做题、但思路很多的学生。

  • pass@k 代表什么：如果你让他试 k 次，他可能会在不同尝试里走出多条路线，其中几条能做对。这代表他“总共会多少种办法”。
  • single-shot 代表什么：如果你只给他一次机会，他未必每次都走到最稳的那条路，所以一次命中的概率可能没那么高。

那 RL 在做什么？

它更像是在强行强化其中一条最稳定、最常成功的路径，让模型以后优先走这条路。结果当然很好理解：

  • 单次作答更稳了
  • 输出更像了
  • 正确率更容易集中到 one-shot 上

但代价也很明显：

  • 其他可行路径被压扁了
  • 生成多样性下降了
  • pass@k 对应的“多次探索空间”未必还保得住

所以论文用 redistribute 这个词非常准确。它表达的不是“创造”，而是“搬运”。不是多了新的资源，而是把原本分散的能力重新摆放了。

这篇论文提出的替代方案是什么

既然作者怀疑 RL 的很多收益其实来自“分布重分配”，那自然会有一个问题：

如果只是想把 base model 里那些更高质量的推理路径更稳定地采出来，为什么一定要改权重？

作者给出的答案是：可以直接在推理时改采样。

更具体地说，他们想采样的目标不再是原始分布 p(x)，而是一个被“加权锐化”后的分布：

$$ \pi(x) \propto p(x)^\alpha $$

其中 \alpha > 1 时，高概率序列会被进一步放大，低概率序列会被进一步压低。

这个想法非常像在问：

如果 base model 已经隐含地知道哪些完整推理轨迹更靠谱，那我能不能在不训练模型的前提下，直接更偏向这些高 likelihood 的完整路径？

这就是论文所谓的 power sampling。

它为什么不等于简单的降温采样

很多人看到这里的第一反应会是：这不就是 temperature < 1 吗？

论文专门花了一节去解释，不是。

原因在于两者“锐化”的对象不同：

  • 低温采样是在每一步对 next-token 分布做锐化
  • power sampling 是对整条序列的联合概率做锐化

这个差别听起来抽象，但含义非常大。

低温采样更像是在当前位置做一个局部贪心决策，它会偏好当前看起来更顺的 token；但 power sampling 关心的是整条未来路径，因此它会更偏向那些“现在看起来不一定最占优，但未来能通向高质量完整解”的 token。

论文的原话是，power distribution 会更偏向“少量但高质量 future paths”的 token，而低温采样更容易偏向“未来分支很多、但每条都不够好”的 token。ar5iv HTML

如果把它翻成人话，大概就是：

  • 低温采样是在做局部稳妥
  • power sampling 更接近在做全局规划

这也是为什么作者会把它和 reasoning 联系起来，而不是只把它当作一个 decoding trick。

为什么不能直接对整句话做 MCMC

理论上，只要目标分布是 p(x)^\alpha，那可以用 Metropolis-Hastings 之类的 MCMC 去逼近它。

但这里马上撞上一个大问题：

语言模型的序列空间太高维了。

如果你直接对长度为 T 的整条输出做 MCMC：

  • 初始化通常很差
  • 候选序列要整段重采样
  • 接受率和混合速度都会变得很难看
  • 最后很可能卡在极高的计算成本和极差的 mixing time 上

论文也明确指出，MCMC 在高维空间里可能出现指数级的 mixing time，而 token 序列恰恰就是一个典型的高维离散空间。ar5iv HTML

所以，如果只是把“整句 MCMC”生搬到 LLM 上，基本是跑不动的。

论文真正有意思的地方：块状的自回归 MCMC

我觉得这篇论文最漂亮的部分，不是“用 MCMC”这件事本身，而是它怎么把自回归结构利用起来，避免整个算法在高维空间里直接爆炸。

作者的做法可以概括成一句话：

不要一开始就在完整长度 T 的空间里采样，而是先采短前缀，再逐步扩展到更长前缀。

他们定义了一串中间分布，大意是：

$$ \emptyset \rightarrow p(x_{0:B})^\alpha \rightarrow p(x_{0:2B})^\alpha \rightarrow \cdots \rightarrow p(x_{0:T})^\alpha $$

这背后的直觉很像“搭桥”：

  • 先在较短前缀空间里得到一个质量不错的样本
  • 再把它作为更长前缀空间的初始化
  • 每次只往后扩一块 B
  • 于是每一步都不是从一片荒漠里重新开始，而是从一个已经比较靠谱的状态 warm start

这一步特别关键。因为它本质上是在用自回归结构，规避高维 MCMC 最怕的“糟糕初始化 + 极慢混合”。

具体算法怎么跑

如果把论文里的 Algorithm 1 翻成更容易读的流程，大概是这样：

1. 先确定目标分布

对于当前前缀长度，对应的目标是：

$$ \pi_k(x_{0:kB}) \propto p(x_{0:kB})^\alpha $$

也就是在当前块长度上，对 base model 的联合概率做幂次锐化。

2. 先用 proposal model 补全一个初始化样本

假设我们已经有一个还不错的前缀 x_{0:kB}。

这时先用 proposal model p_{prop} 往后生成下一个 block，形成一个初始候选。这一步不是最终答案，而是给当前阶段的 MCMC 提供一个起点。

3. 在当前长度上做多轮 MH 重采样

每一轮里做三件事：

  • 随机选一个截断位置 m
  • 保留 m 之前的前缀不动
  • 从 m 开始，用 proposal model 重新生成后半段，得到新的候选序列 x'

然后用 Metropolis-Hastings 的接受率决定要不要接纳 x'。接受率的核心就是两项：

  • 新旧目标概率之比：新序列在 p(x)^\alpha 下是不是更好
  • proposal 的正反转移概率比：也就是经典的 Hastings correction

这一步的本质是：

proposal model 负责“提出新想法”，base model 的幂分布负责“裁决这个想法值不值得留下”。

4. 固定当前块，继续往后长

在当前前缀长度上做完若干轮 MCMC 后，就把得到的高质量样本当作下一阶段的起点，再往后扩一个 block。

最终，你得到的是一条近似从 p(x)^\alpha 采出来的完整序列。

为什么这可以看成一种新的 inference-time scaling

这篇论文还有一个我觉得特别有意思的点：

它把这件事明确放在了 inference-time scaling 的语境里。

传统理解里，我们常说：

  • 训练更多，模型更强
  • 模型更大，能力更强

而这篇论文强调的是第三条轴：

  • 推理时花更多算力，也可以系统性地换来更强的 single-shot reasoning

但这个收益不是免费的。

论文估算过，算法生成 token 的期望成本大约是 O(T^2) 量级，而普通自回归采样大致是 O(T)。ar5iv HTML

直觉上很好理解：

  • 每个 block 都要做多轮重采样
  • 每轮重采样又要重生成一段后缀
  • 序列越长，平均被重生成的后缀也越长

所以它本质上是在拿更多 test-time compute，换更高质量的单次样本。

这也是我觉得它最像当前 reasoning model 发展方向的地方：不是只靠训练期把能力写死，而是在推理期把更好的轨迹搜出来。

论文实验到底说明了什么

论文最有说服力的地方，在于它不是只讲理论，还真的把结果做出来了。

以 Qwen2.5-Math-7B 为例，论文报告的 single-shot 结果大致是：

方法MATH500HumanEvalGPQA
Base0.4960.3290.278
Low-temperature0.6900.5120.353
Power Sampling0.7480.5730.389
GRPO0.7850.5370.399

这个表很值得细看。

它至少说明了三件事：

  • power sampling 的 single-shot 提升不是纸上谈兵，确实能逼近 RL 后训练的效果
  • 它不仅比 base model 强，通常也明显强于简单低温采样
  • 在某些任务上，它甚至可以超过 RL 基线

更关键的是，论文还展示了另一个对它非常有利的结果：

它在 pass@k 上没有像 RL 那样明显地掉多样性。

也就是说，它没有为了 single-shot 的提升，把多次采样时的探索空间压得太狠。这一点正好呼应了整篇论文最核心的论断。

我觉得这篇论文最重要，也最有争议的地方

这篇论文最有价值的地方，不只是“提出了一个新采样算法”，而是它逼着我们重新问一个更根本的问题：

我们到底应该把 reasoning model 的进步理解为“学到了新能力”，还是“更高效地从原有能力里取样”？

我自己的理解是，这篇论文至少把下面几件事说清楚了：

  • RL 的收益里，分布锐化和概率重分配很可能占了很大一部分
  • base model 里潜伏着的能力，可能比我们平时 single-shot 看到的多得多
  • 改推理算法，而不是改模型权重，本身就是一条值得认真投入的路线

当然，它也不是没有局限。

  • 它的推理成本比普通采样高得多
  • 是否能稳定迁移到更长、更开放、更难验证的任务，还需要更多实证
  • “高 likelihood 是否等价于更好 reasoning”本身也不是一个永远成立的命题

所以我不会把它理解成“RL 过时了”，而会把它理解成：

RL 并不是唯一解释，甚至不一定是最干净的解释。

结语

如果让我用自己的话总结这篇论文，我会写成这样：

它最大的贡献，不是发明了一个更花哨的采样器，而是把 RL 的很多收益重新解释成了一种能力重分配。

这件事一旦成立，影响其实非常大。

因为它意味着，未来提升 reasoning model，未必只有“继续后训练”这一条路。也许我们同样应该认真研究：

  • 如何更好地搜索
  • 如何更好地采样
  • 如何在不破坏多样性的前提下，把模型已有的强能力更稳定地激发出来

从这个角度看，这篇论文确实配得上它那个有点挑衅的标题：

你的 base model，可能真的比你以为的更聪明。
