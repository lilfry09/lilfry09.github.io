# 研究地图


这里的技术笔记围绕一个问题展开：**大模型与 Agent 如何学习、推理，并完成真实任务？**

如果你第一次来，不必从最新文章开始。下面按四条研究主线组织已有内容：每条线先给一个入口，再从基础概念走向具体方法和工程问题。想按时间浏览，可以回到[全部文章]({{< relref "/posts/_index.md" >}})或 [AI 归档]({{< relref "/AI/_index.md" >}})。

这份地图整理于 **2026-09-22**，是本站已有文章的阅读导航，不是领域的完整综述。论文版本、研究进展与实验边界以各篇正文标注为准；排列顺序表示阅读依赖，不表示方法排名。

## Agent：数据、环境与系统 {#agent-systems}

**核心问题：怎样让模型不只生成代码，而是在真实环境中完成可验证、可持续的任务？**

这条线把任务、数据、执行环境和 runtime 放在一起看。建议先了解全貌，再分清“模型学到了什么”和“外部系统替它完成了什么”。

## 后训练：RL、偏好与蒸馏 {#post-training}

**核心问题：训练数据从哪里来，反馈如何进入目标函数，更新后的模型又会改变下一批数据什么？**

先理解训练信号与数据分布，再看具体算法，最后进入异步系统。这样不容易把算法名字的变化误当成训练机制的变化。

### 推荐阅读顺序

1. **统一分布视角 · 方法分析**：[SFT、RL 与 OPD：on-policy data]({{< relref "/AI/读SFT、RL与OPD：后训练真正的变量是 on-policy data.md" >}})。对照外部样本、学生自身生成的数据和不同反馈来源。
2. **补齐偏好基础 · 教程**：[Bradley-Terry 与 Plackett-Luce]({{< relref "/AI/面试高频：Bradley-Terry vs Plackett-Luce，奖励建模到底差在哪.md" >}})。从成对比较走向多候选排序，明确偏好数据表达了什么。
3. **看具体目标 · 论文精读**：[GroupDPO]({{< relref "/AI/GroupDPO.md" >}})。把组级偏好目标与省显存实现分开理解。
4. **拓展反馈来源 · 综述**：[从 Self-Distillation 到 Search Distillation]({{< relref "/AI/蒸馏不只是压缩：从 Self-Distillation 到 Search Distillation 的研究地图.md" >}})。比较输出、轨迹、搜索与验证信息如何进入蒸馏。
5. **落到多教师方法 · 论文精读**：[MOPD：多教师能力合并]({{< relref "/AI/读MOPD：后训练正在从单一RL走向多教师能力合并.md" >}})。继续追问学生分布、教师选择与能力保留。

## 模型与推理效率 {#model-efficiency}

**核心问题：改变注意力、位置表示、计算深度或生成方式，分别改变了什么成本，又保留了什么能力？**

这里不是把所有“加速方法”放进一个排行榜，而是区分它们处理的瓶颈。长上下文能用、显存更小、FLOPs 更少与真实延迟更低，需要分别验证。

### 推荐阅读顺序

1. **注意力计算 · 教程**：[线性注意力：从注意力矩阵到可递推状态]({{< relref "/AI/线性注意力从头到尾讲清楚：为什么能从二次方变成线性.md" >}})。从计算结构理解复杂度变化，以及状态压缩的边界。
2. **位置与长度 · 论文精读**：[YaRN：别把 RoPE 拉坏了]({{< relref "/AI/读 YaRN：长上下文扩展，核心不是硬拉窗口，而是别把 RoPE 拉坏了.md" >}})。注意它处理的是位置外推，不是线性注意力的同一个问题。
3. **计算深度 · 多论文综述**：[Looped Transformer 与 Elastic-Depth Post-Training]({{< relref "/AI/Looped Transformer 不只是重复计算：从 LoopFormer 到 Elastic-Depth Post-Training.md" >}})。区分参数共享、执行深度与可调推理预算。

## 优化与训练基础 {#optimization}

**核心问题：损失函数产生怎样的信号，优化器怎样改变更新方向，又需要什么实验才能说明改进是真的？**

这一条既放基础教程，也放自己的研究实验。两者承担不同任务：教程建立工具箱，实验记录保留假设、对照和未解决的问题。

### 推荐阅读顺序

1. **先理解参数更新 · 教程**：[深度学习优化算法]({{< relref "/posts/深度学习优化算法.md" >}})。回顾 SGD、AdaGrad、RMSProp 与 Adam，建立动量和自适应尺度的基本概念。
2. **再理解训练信号 · 教程**：[Focal Loss 与类别不平衡]({{< relref "/AI/Focal Loss 是什么？为什么它能解决类别不平衡问题？.md" >}})。区分改变损失权重与改变优化器方向：它们不是同一个层面的干预。
3. **最后看研究过程 · 实验记录**：[坐标谱优化器：PSGD 坐标与部分 Muon 谱校正]({{< relref "/AI/坐标谱优化器：用动量学习 PSGD 坐标，再做部分 Muon 谱校正.md" >}})。沿着公式、消融、跨 seed 验证与成本比较，区分开发集最佳配置和正式验证配置。

**这条线的检查点：** 同 token 数的质量改善不自动等于同 GPU 时间的优势；局部数学性质也不自动构成完整训练的收敛保证。

## 不按栏目读：三条跨主题路线

| 目标 | 建议顺序 | 最终应能说明 |
| --- | --- | --- |
| 搭建可训练的 Coding Agent | Agent 主线的任务与数据 → AgentENV → 后训练主线的异步 RL → 397B 源码实例 | 一个可执行任务怎样产生轨迹，反馈又怎样进入训练 |
| 理解推理计算如何变成能力 | Looped Transformer → Reasoning with Sampling → 蒸馏地图 | 多算几步、增加采样和把经验训练回模型有哪些区别 |
| 判断一个训练改进是否值得采用 | 基础优化算法 → OLMo 3 → 坐标谱优化器实验 | 数据配方、更新规则与计算预算各自贡献了什么 |

这些顺序是阅读建议，不意味着被串联的方法已经在同一实验里联合验证。
