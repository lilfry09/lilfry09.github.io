这里的技术笔记围绕一个问题展开：大模型与 Agent 如何学习、推理，并完成真实任务？

如果你第一次来，不必从最新文章开始。下面按四条研究主线组织已有内容：每条线先给一个入口，再从基础概念走向具体方法和工程问题。想按时间浏览，可以回到全部文章或 AI 归档。

这份地图整理于 2026-09-22，是本站已有文章的阅读导航，不是领域的完整综述。论文版本、研究进展与实验边界以各篇正文标注为准；排列顺序表示阅读依赖，不表示方法排名。

Agent：数据、环境与系统

核心问题：怎样让模型不只生成代码，而是在真实环境中完成可验证、可持续的任务？

这条线把任务、数据、执行环境和 runtime 放在一起看。建议先了解全貌，再分清“模型学到了什么”和“外部系统替它完成了什么”。

推荐阅读顺序

  1. 建立全貌 · 综述：Coding Agent 论文与工程调研。先认识模型、数据、环境、评测与 harness 之间的关系，不必第一次就读完所有参考资料。
  2. 明确评测对象 · 资料汇报：SWE Agent 数据与评测版图。区分 benchmark、轨迹语料与可运行环境资产；正文提供 HTML 汇报入口。
  3. 拆解任务构造 · 论文精读：FullStack-Agent 的训练与评测数据。观察真实仓库怎样变成训练轨迹和验证用例。
  4. 走向长程任务 · 多论文串讲：从 SWE-Marathon 到 FrontierSWE 与 SWE-Together。继续看阶段反馈、状态管理和长轨迹训练。
  5. 补齐执行条件 · 工程分析：AgentENV：可分叉的沙箱环境。理解环境启动、隔离、快照与恢复为什么会成为训练系统的一部分。

后训练：RL、偏好与蒸馏

核心问题：训练数据从哪里来，反馈如何进入目标函数，更新后的模型又会改变下一批数据什么？

先理解训练信号与数据分布，再看具体算法，最后进入异步系统。这样不容易把算法名字的变化误当成训练机制的变化。

推荐阅读顺序

  1. 统一分布视角 · 方法分析：SFT、RL 与 OPD：on-policy data。对照外部样本、学生自身生成的数据和不同反馈来源。
  2. 补齐偏好基础 · 教程：Bradley-Terry 与 Plackett-Luce。从成对比较走向多候选排序，明确偏好数据表达了什么。
  3. 看具体目标 · 论文精读：GroupDPO。把组级偏好目标与省显存实现分开理解。
  4. 拓展反馈来源 · 综述：从 Self-Distillation 到 Search Distillation。比较输出、轨迹、搜索与验证信息如何进入蒸馏。
  5. 落到多教师方法 · 论文精读：MOPD：多教师能力合并。继续追问学生分布、教师选择与能力保留。

模型与推理效率

核心问题：改变注意力、位置表示、计算深度或生成方式，分别改变了什么成本，又保留了什么能力？

这里不是把所有“加速方法”放进一个排行榜，而是区分它们处理的瓶颈。长上下文能用、显存更小、FLOPs 更少与真实延迟更低，需要分别验证。

推荐阅读顺序

  1. 注意力计算 · 教程：线性注意力：从注意力矩阵到可递推状态。从计算结构理解复杂度变化，以及状态压缩的边界。
  2. 位置与长度 · 论文精读：YaRN：别把 RoPE 拉坏了。注意它处理的是位置外推，不是线性注意力的同一个问题。
  3. 计算深度 · 多论文综述：Looped Transformer 与 Elastic-Depth Post-Training。区分参数共享、执行深度与可调推理预算。

优化与训练基础

核心问题：损失函数产生怎样的信号，优化器怎样改变更新方向，又需要什么实验才能说明改进是真的？

这一条既放基础教程，也放自己的研究实验。两者承担不同任务：教程建立工具箱，实验记录保留假设、对照和未解决的问题。

推荐阅读顺序

  1. 先理解参数更新 · 教程：深度学习优化算法。回顾 SGD、AdaGrad、RMSProp 与 Adam，建立动量和自适应尺度的基本概念。
  2. 再理解训练信号 · 教程：Focal Loss 与类别不平衡。区分改变损失权重与改变优化器方向：它们不是同一个层面的干预。
  3. 最后看研究过程 · 实验记录：坐标谱优化器：PSGD 坐标与部分 Muon 谱校正。沿着公式、消融、跨 seed 验证与成本比较，区分开发集最佳配置和正式验证配置。

这条线的检查点： 同 token 数的质量改善不自动等于同 GPU 时间的优势；局部数学性质也不自动构成完整训练的收敛保证。
